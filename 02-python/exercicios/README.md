# Fichas de exercícios de Python

Uma ficha de exercícios é para treinares sozinho, depois de fazeres o laboratório. Os exercícios não têm a solução à vista: tentas tu, e as resoluções trabalham-se na aula. Se ficares preso, a pista de um exercício, quando a tem, ajuda sem dar a resposta. A ligação "Rever" leva-te à secção do guia de que precisas.

Uma ficha não é um laboratório. O [laboratório](../laboratorios/README.md) guia-te passo a passo, com a solução pelo caminho, e a ficha mostra o que já consegues fazer sem ajuda. A matéria de cada tema está no guia, na pasta da área, e o [índice da área](../README.md) liga a cada um.
