# Algoritmos

Primeira área da disciplina de Linguagens de Programação. Aprender a analisar um problema, a escrever os passos que o resolvem e a testar se esses passos funcionam, tudo antes de escrever a primeira linha de código.

São **25 horas**, repartidas por cinco partes de 5 horas cada.

Cada parte tem um guia, para ler e trabalhar em aula, e uma ficha de exercícios, para fazeres sozinho. As partes 02, 03 e 04 têm também um laboratório, com os passos a seguir no computador para desenhares os fluxogramas na aplicação. Os guias trazem exemplos explicados até ao fim; as fichas trazem só os enunciados, porque a ideia é tentares antes de veres como se faz. As resoluções são trabalhadas em aula com o professor.

Para a primeira parte bastam papel e caneta. A partir da segunda vais precisar também do diagrams.net, uma aplicação gratuita de desenho de diagramas que funciona no browser, em app.diagrams.net, sem criar conta. O laboratório da parte 02 ensina a usá-la desde o início.
